# Motor Selection

Web inicial para Motor Selection, creada con Next.js + Tailwind CSS.

## Ejecutar en local

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Subir a Vercel

1. Sube este proyecto a GitHub.
2. Entra en Vercel.
3. Importa el repositorio.
4. Deploy.

## Editar coches

Modifica el archivo:

```txt
/app/data/cars.ts
```
